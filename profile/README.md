# deCloud

**一个 API Key 调用全球顶级 AI 模型**
*One API key to every frontier AI model*

一个 API Key 覆盖对话、图像、视频、语音、转写、嵌入、重排七类模型;对外统一 OpenAI 兼容协议,
另提供 Anthropic Messages 与 OpenAI Responses 两个端点,原有代码只改「地址 + Key」两处。
目录同时收录直连厂商与聚合目录来源,每个模型的上游在模型页逐个标注。按 token 计费,失败不计费。
