### 为什么用它

deCloud 是一个 **AI 模型接入层**:一个 API Key 覆盖对话、图像、视频、语音、转写、嵌入、重排七类模型,
对外统一 OpenAI 兼容协议,另提供 Anthropic Messages 与 OpenAI Responses 两个端点 —— 原有代码只改「地址 + Key」两处。

- **接入与模型解耦** —— 接入写一次,之后模型换代与它无关
- **一套协议接所有** —— OpenAI 兼容 + Anthropic Messages + OpenAI Responses
- **目录聚合** —— 直连厂商与聚合目录收在一处,每个模型的上游在模型页逐个标注
- **权限与用量合一** —— 权限、用量、明细逐笔可核,支持导出

### 支持哪些客户端

NextChat · Chatbox · LobeChat · Open WebUI · Cherry Studio · Cursor · opencode · Claude Code · Codex
—— 能改自定义接口地址的客户端都能接。
